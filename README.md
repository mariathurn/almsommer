# Schafkopf

The Bavarian card game Schafkopf as an Expo (React Native) app for iOS, Android and the web. You play South against three computer opponents.

```bash
npm install
npm start        # Expo dev server; press i (iOS), a (Android) or w (web)
npm test         # Unit tests for the game rules
```

On a phone, install **Expo Go** and scan the QR code that `npm start` prints. See [README_CODEBASE.md](README_CODEBASE.md) for how the code is organised.
